# 🎮 VisionPlay – Web Mini Arcade

Welcome to **VisionPlay**, a fully interactive mini-game arcade built with HTML, CSS, and JavaScript.  
This project started as a beginner practice website and evolved into a polished arcade experience featuring multiple games, random facts, customization, sound effects, and saved stats.

# 🎮 Mini Games Included

## **1. Click Race**
Test your clicking speed!

- Timed clicking challenge  
- Preset rounds: **5s**, **10s**, **15s**, **20s**  
- Custom timer (3–60 seconds)  
- Tracks best score & CPS (clicks per second)  
- Sound effects + button animations  

---

## **2. Jump Runner**
A side-scrolling runner game with obstacles.

- Endless mode (run forever)  
- Goal mode (reach 250m to win)  
- Difficulty levels:  
  - Easy → 5 lives  
  - Normal → 3 lives  
  - Hard → 1 life  
- Character jump animation  
- Parallax background  
- Best distance & time saved  
- Lives displayed as heart icons  

---

## **3. Reaction Test**
Measure your reaction speed.

- Classic Mode – click when the box turns green  
- Average Mode – 5-round average  
- Hard Mode – faster and unpredictable  
- Best reaction time saved

# 🎨 Customization Features

VisionPlay allows full UI customization:

- Light, Dark, and Neon themes  
- Changeable accent color  
- Changeable font  
- Edit the site title  
- Sound On/Off toggle  
- Background music  
- Smooth scrolling navigation  
- VP Neon favicon  

---

# 💾 Saved Data

Using localStorage, VisionPlay remembers:

- Best Click Race score  
- Best Jump Runner time & distance  
- Best Reaction Test score  
- Theme choice  
- Accent color  
- Sound settings  

Your data stays even after refreshing or closing the page.
